C2 · Auto-capitalise words (item 2)

#FieldAll fields (rec.)Names onlyWhy
1Card labelWordsWordsAlways a name — “Car Insurance”
2Data nameWordsWords“Policy No”, “Garage”
3Data valueWordsnoneOften a name, sometimes an e-mail or an ID
4Date nameWordsWords“Policy Expiry”
5Category nameWordsWords“Identity Docs”
6Search boxnonenoneSearch is case-insensitive; capitals would only get in the way
7Typed confirmationsnonenoneDELETE / RESET are already upper case by hand
Honest limit: this sets the keyboard’s capitalisation mode. Gboard, Samsung Keyboard and SwiftKey all honour it; a few third-party keyboards ignore it, and nothing forces the letter — you can always type lower case. InfoDeck does not rewrite what you typed, because that would mangle values like kri.subsc@gmail.com.
