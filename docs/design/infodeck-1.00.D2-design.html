InfoDeck — v1.00 · D2 design

Second round. Adds categories (create, move cards between them), a one-open-at-a-time accordion, and the Group by / Sort by / Filter controls. Mock date is Tue 18-Aug-2026; every countdown is computed from it. D1 stays valid for everything not touched here — see section C9.

DESIGN ONLY · nothing queued · nothing built Reply by tag: “S1.4 → chips”, “Q11 → b”, or “defaults” = all recommended
⚑ Conflict to settle before anything else (Q11). D1 already had a container called Deck (Insurance, Vehicle, Warranties…). Your “category” looks like the same thing under a different name, so this design renames Deck → Category everywhere and keeps exactly one level. Home becomes one screen: the category accordion, no drill-down into a separate deck screen.
The alternative is two levels (Deck ▸ Category ▸ Card) — more taps, more moving parts, and every card then needs both. I do not recommend it, but say the word and I redraw. Everything below assumes one level.

C5 · Accordion rules

1Opening a sectionThe previously open one collapses in the same animation (Q12). The opened section scrolls to the top of the viewport.

4Changing group / sort / filterSections collapse; if exactly one section survives the filter, it opens by itself.
5SearchGrouping is suspended — matches show as one flat list with a category chip on each. Clearing search restores the previous state.

C7 · Key date — what “expiry” means

SrNo.PointRule
1WhyDate variables are freely named (“Policy Expiry”, “Warranty end”, “Renewal”), so the app has no way to guess which one “expiry” means. The star makes it explicit.
2DefinitionKey date = the date variable marked ★ on the card. Exactly one; the first date added is starred automatically.
3Used byHome preview line · Expiry-month and Expiry-window grouping · Expiry-date sorting · the expiry filter · the category summary line.
4No datesCard lands in “No date”, sorts last, and shows its first data variable in the preview line instead.
5Alternative (Q13)Instead of the star: always use the nearest upcoming date on the card. Zero setup, but a card silently changes group as dates pass. I recommend the star.
