InfoDeck — return from a beta to the stable version

Design infodeck-1.15.0.D2 · latest stable on GitHub: v1.15.0 · approach chosen by Krishna: both — (1) betas keep the base stable's versionCode so the return is an in-place reinstall, and (2) a guided backup → uninstall → reinstall → restore path when in-place is impossible.

Android rule: an APK with a lower versionCode is refused Equal versionCode installs over the top, data kept ⚑ Behaviour change: beta APKs no longer carry their target versionCode

Honest limit: betas already on a phone that were built before this change (for example 2.0.0-beta.78, versionCode 2000000) do not contain this code and carry a high versionCode. They cannot be returned in place. The one-time way back for those is the manual version of path (2): make a JSON backup in that beta, uninstall, install the stable, restore. Attached PDF/Word files in that beta are not in a JSON backup, so save them out first.
