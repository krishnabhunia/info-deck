New Android app (Kotlin / Jetpack Compose, minSdk 26 / target 34). Decks of information cards; each card = Label + Data variables (alphanumeric) + Date variables + Schedulers that ring relative to a chosen date variable. Working name InfoDeck — see Q1. SrNo.UnitAmount rangeRing date (java.time)Example · base = Policy Expiry 11-Oct-2026

C3 · Ring engine

SrNo.AspectDesign
1AlarmOne AlarmManager exact alarm (setExactAndAllowWhileIdle) for the earliest due ring only; when it fires, the next one is planned. Falls back to setAndAllowWhileIdle when exact alarms are not permitted (S9.3 says so).
2Re-planningOn BOOT_COMPLETED, TIME_SET, TIMEZONE_CHANGED, app open, every save, and a daily WorkManager sweep at 00:05 (belt and braces).
3Missed while phone offFires at the next re-plan, marked “late” in History; never silently dropped.
4PermissionsPOST_NOTIFICATIONS (13+), SCHEDULE_EXACT_ALARM (12+), RECEIVE_BOOT_COMPLETED, VIBRATE, USE_BIOMETRIC (only if Q9 = yes). No internet permission unless Q8 = cloud.
5NotificationChannel “Reminders” (high). One notification per scheduler + auto group summary. Actions Done · Snooze · tap-to-open (S7).
6Failure pathsEvery scheduling call guarded; failures → Logger.e → Error Logs; a failed alarm plan is retried on the next re-plan trigger.
