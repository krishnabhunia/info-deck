InfoDeck — v1.9 · D1 design

Renaming a file changes its name only. The extension (.pdf, .docx) is locked; changing it takes a deliberate second step and then a confirmation — because a new extension never converts the file, it only changes how other apps treat it. Mock date Wed 14-Oct-2026.

DESIGN ONLY · nothing built · no version bump Reply by tag: “S4.3 → chips only”, “Q2 → b”, or “defaults” = all recommended
Checked in the 1.9 source. File rename reuses NameDialog in TagFileUi.kt — the tag-rename box. The whole file name is one free field, and its onValueChange keeps only TagRules.MAX_NAME = 24 characters. On any name longer than 24, the first key press cuts the end off — the extension goes first. FileRules.sanitise also cuts at 80 from the end. Logged as B13 and fixed in the same change.

C1 · Rules

SrNo.RuleDetail
1DoorCard editor ▸ Files ▸ ⋮ ▸ Rename — the only place a file is renamed (the card view's Rename already routes to the editor).
2SplitExtension = the text after the LAST dot, when it is 1–8 letters/digits and something comes before the dot. Policy v2.1.pdf → name Policy v2.1 + pdf. Scan → no extension (the lock chip reads none; Change extension… can add one). .hidden → all name.
3Step 1Name box holds the name only, selected on open; extension chip read-only with a lock; live “Saved as” preview.
4Name-only saveSaves straight away — no extra step, no confirm.
5Step 2Change extension… unlocks: amber Extension box (dot fixed, letters/digits, max 8), chips .pdf · .doc · .docx with the real type ticked, permanent warning, Keep .pdf to re-lock; Save turns into Save….
6Step 3Save… with a different extension opens the confirm. Nothing is written until Change to .docx. Keep / Back / outside → Step 1, extension locked again, name edits kept.
7What counts as a changeCompared ignoring case: .PDF → .pdf is a plain save Q1. A blank extension means “remove the extension” and is confirmed (“Remove the extension?”).
8Typed extensionName ending in a known extension → amber hint + shortcut into Step 2 Q5.
9On diskNothing moves or converts: only the display name changes. The real type (MIME) is kept, so Open and Share still hand apps the real type under the new name.
10Length80 characters for the whole name. If it must be cut, the NAME part is cut — never the extension. The 24-character tag limit no longer applies to file names (B13).
11File rowMiddle cut keeps the extension visible Q7; amber “Really a PDF” line while they disagree Q3; Undo snackbar 5 s Q4.
12UnchangedTag rename and category rename keep today's plain name box (tags keep the 24 limit). Attach, Open, Share and Remove are untouched.
